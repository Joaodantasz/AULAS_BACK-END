// ======================================================
// JAVASCRIPT (JS) - HISTÓRIA E CONCEITOS BÁSICOS
// ======================================================

 O JavaScript é uma linguagem de programação criada em 1995.
 Seu criador foi Brendan Eich, que trabalhava na Netscape.

 Inicialmente, a linguagem recebeu o nome de Mocha.
 Depois passou a se chamar LiveScript.
 Finalmente, recebeu o nome JavaScript.

IMPORTANTE:
    JavaScript e Java são linguagens diferentes.
    Apesar dos nomes parecidos, elas possuem características
    e objetivos diferentes.

// ------------------------------------------------------
// ONDE O JAVASCRIPT É USADO?
// ------------------------------------------------------

// O JavaScript ficou muito conhecido por ser usado em
// páginas da internet para criar interatividade.

 Exemplos:
 - Botões
 - Menus
 - Formulários
 - Animações
 - Validação de dados
 - Jogos
 - Aplicações web

 Atualmente, JavaScript também pode ser usado fora do
 navegador, por exemplo, com Node.js.

 // ------------------------------------------------------
// PRINCIPAIS CARACTERÍSTICAS
// ------------------------------------------------------

// JavaScript é uma linguagem:
// - Fácil de começar a aprender
// - Dinâmica
// - Interpretada/JIT nos ambientes modernos
// - Muito utilizada no desenvolvimento web
// - Compatível com HTML e CSS
//
// HTML → estrutura da página
// CSS  → aparência da página
// JS   → comportamento e interatividade

// ------------------------------------------------------
// EXEMPLO SIMPLES
// ------------------------------------------------------

let nome = "João";
console.log("Olá, " + nome);

"let" cria uma variável.
 "console.log()" mostra uma informação no console.

// ------------------------------------------------------
// CURIOSIDADE

 O padrão oficial do JavaScript é chamado ECMAScript.
 Ele define as regras e recursos da linguagem.

 Atualmente, JavaScript é uma das principais linguagens
 utilizadas no desenvolvimento de aplicações. //
